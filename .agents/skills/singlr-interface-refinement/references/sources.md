# Referencia y adaptación

Fuente: Charlie Aufmann y Maxime Heckel, «A calmer interface for a product in motion», Linear Now, 12 de marzo de 2026.
https://linear.app/now/behind-the-latest-design-refresh

Esta skill transforma en pasos de trabajo las observaciones del equipo de diseño de Linear: prioridad del contenido frente a controles de orientación; navegación lateral más discreta; pestañas compactas; uso intencional de iconos; bordes y separadores con menor ruido; experimentación sobre paletas y design tokens; comparación rápida de variantes con feature flags; colaboración con agentes de programación para prototipos e instrumentos internos.

**Límites:** Son decisiones de Linear para su producto, no requisitos prescriptivos de Singlr. No se adopta su interfaz literalmente. Las relaciones visuales, el sistema material y las interacciones concretas se definen y validan dentro de Singlr.
